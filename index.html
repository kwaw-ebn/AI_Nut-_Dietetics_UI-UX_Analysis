System Architecture
Full-stack design — React · Node.js/Express · PostgreSQL · Python microservice

🖥 Frontend (React.js)

  • React 18 + Vite
  • Recharts / Chart.js
  • Axios for API calls
  • React Router v6
  • Tailwind CSS
  • Papa Parse (CSV)
  • SheetJS (XLSX)

⚙ Backend (Node.js/Express)

  • Express.js REST API
  • Multer (file upload)
  • node-postgres (pg)
  • JWT Authentication
  • Axios → Python service
  • Winston logging
  • Joi validation

🐍 Python Microservice

  • FastAPI
  • Pandas + NumPy
  • SciPy (stats)
  • NLTK / spaCy (NLP)
  • Seaborn (charts)
  • Scikit-learn (clusters)
  • TextBlob (sentiment)

Sample Code — File Upload (Node.js)
// routes/upload.js const multer = require('multer'); const Papa = require('papaparse'); const XLSX = require('xlsx'); const storage = multer.memoryStorage(); const upload = multer({ storage, limits: { fileSize: 50 * 1024 * 1024 } }); router.post('/api/upload', upload.single('file'), async (req, res) => { const { buffer, mimetype, originalname } = req.file; let data; if (mimetype === 'text/csv') { const csv = buffer.toString('utf-8'); data = Papa.parse(csv, { header: true, skipEmptyLines: true }).data; } else { const wb = XLSX.read(buffer, { type: 'buffer' }); data = XLSX.utils.sheet_to_json(wb.Sheets[wb.SheetNames[0]]); } const datasetId = await db.saveDataset({ filename: originalname, data }); await axios.post('http://python-service:8000/analyze', { datasetId }); res.json({ datasetId, rowCount: data.length }); });
